# Sistema de Estoque de Veículos

Sistema web para gerenciamento e exposição de estoque de veículos.

## Tecnologias

* Next.js
* React
* TypeScript
* Tailwind CSS
* MySQL
* Better Auth

## Funcionalidades

* Catálogo de veículos
* Busca por marca e modelo
* Filtros por características
* Página de detalhes dos veículos
* Área administrativa
* Autenticação
* Cadastro e gerenciamento de veículos
* Integração com MySQL através das API Routes do Next.js
* Interface responsiva
